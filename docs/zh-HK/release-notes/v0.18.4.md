# v0.18.4 

_發布日期： 2026-08-04_

### 優化

- 修復了開啟交易密碼保護後，帳戶設定（如資產頁面的幣種偏好）始終不生效的問題。
- 修復了在自訂分欄佈局或恢復上次佈局後，獨佔一個標籤分組的面板（如盈虧分析）可能一直空白、不載入資料的問題。
