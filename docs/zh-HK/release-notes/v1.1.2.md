# v1.1.2 

_發布日期： 2026-11-10_

### 優化

- 修復了 LongbridgeAI 語音輸入識別的問題。
- 修復了持倉切換市場分組可能不生效的問題。
- 修復了帶止盈止損的訂單主單成交後，待觸發的止盈止損線從 K 線上消失、無法拖曳改價的問題。
- 提升了 Windows 上的運行穩定性，優化了系統睡眠喚醒後的恢復表現。
- 修復了期權鏈組件改為不聯動或其他聯動分組後，期權表格和期權異動沒有跟隨自己分組的問題。
