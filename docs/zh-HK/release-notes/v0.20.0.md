# v0.20.0 

_發布日期： 2026-09-09_

### 新增
- 支援用戶在應用程式內完成 OpenAPI 範圍授權，提升便捷性。

### 優化
- 優化了「問 AI」功能的上下文傳遞，確保在 ACP 路徑中保持一致。
- 調整了篩選器邏輯，支援從篩選參數中繼承回報率和工具排序規則。
