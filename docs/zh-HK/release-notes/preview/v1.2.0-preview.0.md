# v1.2.0-preview.0  <Badge type="warning" text="preview" />

_發布日期： 2026-11-09_

### 新增

- **訊息中心**：標題欄新增訊息中心入口，各類通知集中在獨立視窗查看，訂單訊息可直接打開訂單詳情；從訊息跳轉長橋網頁時自動登入，無需再輸入賬號。
- **個股詳情**：新增「ETF」標籤頁，可查看與該股票相關的 ETF、槓桿及反向 ETF，並按市場篩選；槓桿 / 反向 ETF 詳情頁同時顯示所追蹤的正股，方便對照走勢。
- **自選股**：支援透過 CSV / Excel 匯入匯出自選股，匯入前可按分組預覽變化，方便從其他平台遷移或批量整理。
- **財報日曆**：新增行業和類型篩選，並展示按年數據，更快找到關注公司的財報。
- **圖表**：分時圖標出當日最高價和最低價；水平線類畫線在價格軸上顯示對應價格，讀數更直觀。
- **LongbridgeAI**：輸入框自動 @ 當前查看的標的，打開即可直接提問。
- **導航**：支援滑鼠側鍵前進 / 後退，在頁面間切換更順手。

### 優化

- 標題欄更新入口改為圖示，用顏色區分下載中、安裝中、待重啟和失敗狀態；點擊「待重啟」直接重啟完成更新。
- 「關於」和「更新日誌」改為獨立視窗打開，未登入時也能查看。
- 修復了主單成交後，止盈止損附加單不在 K 線圖上顯示、無法拖拽改價的問題。
- 修復了 Windows 系統喚醒後、部分 Windows 裝置啟動時，以及策略編輯器解析腳本時可能崩潰的問題。
