# v0.18.2-preview.0  <Badge type="warning" text="preview" />

_發布日期： 2026-07-23_

### 新增

- **財務**：個股財務新增「業績」「收入構成」「股東回報」三大板塊，財報關鍵數據圖形化呈現，幫助快速把握公司基本面。
- **交易**：多腿期權組合（MLEG）支援市價單下單，組合策略不再局限於限價方式。
- **交易**：下單預估費用支援卡券抵扣前後對比展示，預覽金額與實際凍結口徑一致、所見即所得。

### 優化

- 平倉操作統一為強制二次確認後直接提交，不再彈出下單面板，流程更快且避免誤操作。
- 「當日訂單」快捷改單升級：數量與委託價可直接輸入，改單更高效。
- 修復條件單選擇市價類型時，預估金額和最大可買數量未按觸發價計算的問題。
- 誤按提示浮層現在會列出包含所按修飾鍵的全部快捷鍵，且主快捷鍵優先展示，便於發現可用操作。
- 修復期權鏈在切換標的或到期日後，可見合約行情不載入的問題。
- 期權策略簡介的盈虧示意圖全新設計，用漲跌色區分盈虧區間並標註盈虧平衡點與最大盈虧，策略特徵一目了然。
- 修復深度擺盤在切走標籤頁再切回後數據不再更新的問題。
- 持倉右鍵選單的「買入」「賣出」按漲跌色顯示，操作方向更醒目。
