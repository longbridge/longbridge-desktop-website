# v1.0.0-preview.0  <Badge type="warning" text="preview" />

_發布日期： 2026-09-07_

### 新增

- **AI 助手**：發佈 AI 助手。可以用自然語言查行情、分析個股、查看帳戶資產與盈虧，@ 引用個股與訊號補充上下文，回答中直接嵌入行情卡片、分時與 K 線圖表；還能生成量化策略、解讀回測報告。提供側邊欄與全螢幕兩種模式，全螢幕下可搜尋歷史對話。
- **交易**：新增止盈止損訂單模板，下單表單可一鍵套用、設定頁統一管理，不必每次手動填寫觸發價。
- **期權**：期權分析新增「行權價分佈」板塊，用看漲/看跌雙向柱狀圖與價內/價外匯總表看清籌碼分佈。
- **交易**：新增港股保價提醒，下單價格偏離盤口過遠時提前說明訂單會被暫存，不會再誤以為下單失敗。
- **網格交易**：新增「網格交易」標籤頁模板，日 K 圖表與網格訂單、今日/歷史訂單同屏排列，開箱即可開始網格策略。
- **訂單**：成交推送接入系統通知中心，App 在背景執行時也能第一時間收到成交提醒。

### 優化

- 個股詳情面板改為響應式佈局，窄視窗下欄位自動換列。
- 優化圖表快捷交易：下單後數量與焦點不再殘留，止盈止損可一鍵填入全部持倉數量，委託列表同步顯示該數量。
- 期權標籤頁全面接入面板延遲載入，不在畫面上時不再發起網路請求與行情訂閱，背景開銷明顯下降。
- 圖表繪圖工具改用專屬圖示並重新命名斐波那契系列，工具更容易分辨。
- 盈虧頁的顯示幣種改由帳戶偏好決定，與帳戶設定保持一致。
