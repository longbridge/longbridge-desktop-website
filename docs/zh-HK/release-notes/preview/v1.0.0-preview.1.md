# v1.0.0-preview.1  <Badge type="warning" text="preview" />

_發布日期： 2026-09-08_

### 新增
- 在附加訂單開關處新增懸停提示顯示禁止原因，協助了解功能不可用的具體原因。

### 優化
- 優化籌碼分佈入口在切換指標面板時的顯示穩定性，避免發生跳動情況。
- 量化程式碼列表區域的摺疊狀態現已支援持久化，方便用戶自訂介面配置。
