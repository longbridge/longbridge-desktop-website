# v1.0.0-preview.4  <Badge type="warning" text="preview" />

_發布日期： 2026-10-22_

### 新增

- **交易**：港股、新加坡股票支援碎股單，零散股數可以直接買賣；數量不符合整手時會提示並引導切換為碎股單。
- **交易**：卡券按所選交易時段配對（如盤中、盤前盤後、夜盤），並結合本單預估費用推薦抵扣最多的那張，不再浪費面額大的卡。
- **市場**：新增財報日曆，按週 / 月查看各市場的財報公佈安排，點擊個股即可查看歷史業績與市場預期，方便提前做好財報季準備。
- **自動更新**：發現新版本後預設在背景下載並安裝，完成後在標題列提示重新啟動，不再打斷操作；可在「設定 > 常規」中關閉。

### 優化

- 組合期權下單時逐腿檢查風險披露，賣出期權腿時正確彈出沽空提醒；沽空期權提醒新增「下次不再提示」選項。
- 修復了切換帳戶後，交易面板的訂單類型和數量單位仍沿用舊帳戶的問題。
- 修復了盈虧排行排序與翻頁異常、今日統計切換帳戶後顯示舊數據、持倉詳情顯示為 `--` 等問題。
- 修復了本地數據庫檔案損壞時應用程式啟動即當機的問題，現會自動備份並重建；修復了觸控 ID 不可用時點擊指紋按鈕導致的當機。
