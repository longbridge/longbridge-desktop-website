# v0.17.0-preview.0  <Badge type="warning" text="preview" />

_發布日期： 2026-06-04_

### 新增

- **行情**：新增「股東」面板，可查看個股主要股東及持倉結構，方便研究股權變化。
- 新增 macOS 選單列狀態項與下拉選單，可直接在選單列查看自選股即時行情、切換分組並快速喚起主視窗，不開啟主視窗也能盯盤。
- Windows 支援「關閉至系統匣」，關閉視窗後應用程式在背景繼續執行，可透過系統匣圖示快速還原。
- **登入**：新增長橋香港 / 長橋新加坡地區切換，可按所選地區動態切換。

### 優化

- **設定**：新增「聲音設定」，可單獨開關股價提醒聲音，免打擾時段不再被提示音打擾。
- **搜尋**：股票搜尋新增「清除歷史」按鈕，可一鍵清空搜尋記錄。
- 優化下單 / 撤單通知，訊息中顯示具體訂單詳情（方向、數量、標的、委託價），追蹤單以反彈 / 回落格式呈現，便於核對。
