# v1.0.0 

_發布日期： 2026-09-07_

### 新增

- **LongbridgeAI**：能思考，會行動，隨時為您分析的 AI 助手正式上線。
  - 即時喚起：側邊欄與全螢幕兩種形態，任意介面一鍵提問。
  - AI 個股分析：一次提問覆蓋基本面、技術面、消息面，自動匯總成結論。
  - AI 智能選股：一句話說清選股思路，AI 自動轉成篩選條件。
  - AI 趨勢解讀：框選一段區間，AI 解讀走勢成因。
- **交易**：新增止盈止損附加單填寫模板，下單表單一鍵快捷套用，無需每次手動填寫。
- **期權**：期權分析新增「行權價」統計模組，支援成交量與持倉量分析，籌碼堆在哪裡一目了然。
- **交易**：新增港股保價提醒。下單時價格偏離盤口過遠會彈窗提醒，訂單列表中訂單被保價時也會顯示提示文案，不會再誤以為下單失敗。
- **網格交易**：新開標籤頁新增「網格交易」模板，一鍵點選即可使用，專業的波段交易工具。
- **訂單**：成交推送接入系統通知中心，桌面端在背景執行時也能第一時間收到成交提醒。

### 優化

- 個股詳情面板升級為響應式佈局，窄視窗下欄位自動換列，小螢幕也能讀全。
- 圖表快捷交易更順手：下單後數量與焦點不再殘留，止盈止損可一鍵填入動態全倉。
- 圖表畫線中，數據列畫線工具圖示優化，下拉選單裡一眼分得清。
