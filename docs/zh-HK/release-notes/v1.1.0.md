# v1.1.0 

_發布日期： 2026-10-26_

### 新增

- **市場**：新增財報日曆，可查看各大公司的財報發佈日程，重要財報不錯過。
- **交易**：港股、新加坡股支援碎股單，不足一手的零股也能直接買賣；金額下單同樣適用於碎股單。
- **交易**：免佣卡、平台費卡和股票現金卡支援區分美股交易時段，期權盤前時段也能用上對應的卡券。
- **自動更新**：發現新版本後在背景自動下載並安裝，完成後在標題欄提示重啟，不打斷當前操作；可在「設定 > 常規 > 軟件更新」中關閉。

### 優化

- **交易**：持倉帶碎股時，條件單可按碎股數量下單和改單，點「持倉可賣」即可全部賣出。
- **交易**：沽空期權提醒和圖表批量撤單確認支援「不再提示」，不想每次確認時可一鍵勾選，之後可在設定中重新開啟。
- 再次點擊側欄的「市場」「自訂」等入口時，回到上次停留的子頁面，不再總是跳回首頁。
