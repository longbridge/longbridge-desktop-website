# v0.18.0 

_發布日期： 2026-07-15_

### 新增

- **交易**：新增自訂交易快捷鍵，支援市價 / 買一價 / 賣一價快捷買賣、一鍵市價平倉與快速撤單，可按市場預設快捷下單數量，不離開鍵盤即可完成交易。詳見[使用說明](https://support.longbridgehk.com/topics/longbridgepro_new/desktop-gpui-hotkey?locale=zh-HK)。
- **交易**：新增組合期權支援，覆蓋下單、盈虧分析、訂單推送與持倉展示，期權組合策略可直接在桌面端下單和追蹤。
- **交易**：新增美股 MOC（收市競價）訂單類型，方便按收市價成交。
- **期權**：新增期權面板，整合期權鏈、期權異動、期權分析三個子頁籤，期權數據一處查看。
- **資產**：持倉列表新增「同標的衍生品合併」展示，正股與其期權、組合期權、輪證歸組並匯總盈虧，持倉結構一目了然。
- **個股**：新增 ETF 概覽面板，展示追蹤指數、費率、晨星評級、歷史業績、成分與派息等資料，協助在買入前快速了解。

### 優化

- 優化期權鏈載入效能，僅載入可見區域的行情並懶渲染更新，長列表滾動更流暢。
- 自選列表支援顯示自訂的股票備註名。
- 新聞頁籤移入行情面板組，瀏覽個股資訊更順手。
- 持倉右鍵選單的「買入 / 賣出」按漲跌色顯示，操作方向一眼可辨。
- 持倉比例、收市價等欄改為按數值排序，修復排序異常的問題。
