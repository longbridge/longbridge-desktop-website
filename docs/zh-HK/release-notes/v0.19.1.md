# v0.19.1 

_發布日期： 2026-08-20_

### 優化

- 修復了編輯器在部分語法高亮場景下可能意外退出的問題，編輯含中文等多位元組字元的內容時更穩定。
- 修復了縱向列表偶爾出現多餘橫向捲軸的問題，超長文字現在會按列表實際寬度正確截斷顯示。
