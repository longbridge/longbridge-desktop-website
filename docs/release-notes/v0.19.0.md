# v0.19.0 

_Release Date: 2026-08-19_

### New Features

**Screening & quant**

- **Screener**: Added a stock screener with multi-dimensional filters across markets, industries, themes, range indicators and technical indicators — range conditions can be dragged on the distribution chart, and a filter combination can be saved as a strategy for reuse.
<video src="https://assets.lbkrs.com/uploads/eca49d71-c8f8-4f8a-bc37-30edb934c20b/Screener.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>
- **Quant**: Added a quant workspace for authoring indicator and strategy scripts, chart syncing and strategy backtests; once a backtest finishes, the performance report, net value curve and buy/sell markers are all available.
<video src="https://assets.lbkrs.com/uploads/a78a6d7c-a64e-4763-aa70-f74f631cec2a/Quant.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>

**Trading**

- **Grid Trading**: Added grid trading — for stocks that move within a fluctuating range, set up a buy-low/sell-high strategy and let it run inside the price range you specify, and it can be paused, restarted, adjusted or terminated at any time.
<video src="https://assets.lbkrs.com/uploads/3b21b781-677f-42d5-8f22-ee70e3c39973/Grid.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>
- **Trade**: The take-profit/stop-loss ticket has been redesigned for a more intuitive way to set stop levels, and now supports dynamic "Full position" and "Trigger price" parameters that follow position changes automatically, for greater flexibility.
<video src="https://assets.lbkrs.com/uploads/65032bfc-4738-426d-87e3-c0be30588879/TP-SL.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>

**Monitoring & research**

- **Quotes**: Added quote change alerts to stock details, pushing that stock's alerts such as limit-up and block trades in real time.
<video src="https://assets.lbkrs.com/uploads/4d435b8b-ac15-49c5-8239-210e36227346/Big.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>
- **Watchlist**: The list view now supports drag-and-drop sorting, with pinned stocks reordered within the pinned segment, so there is no need to open group management to change the order.
<video src="https://assets.lbkrs.com/uploads/6d576317-2705-4bf4-8f56-1570b0f500be/Drag.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>
- **Chart**: Drawings can now be locked per shape or globally, preventing accidental dragging of finished lines while reading charts, with the lock state kept in sync with mobile.
- **Layout**: Added an adaptive layout to custom pages — widgets dragged in are arranged automatically and fit the screen size, for a more flexible layout.
- **Financials**: Added a "Financial Score" panel covering the latest rating, a five-dimension radar chart, score criteria details and the industry rating distribution, making it easy to see where a stock stands among its peers.
<img width="3584" height="2324" alt="score" src="https://assets.lbkrs.com/uploads/945a3959-f08c-4510-83aa-252ac8bf3ac0/Score.png" />

### Improvements

- Placing a US market order outside regular trading hours now shows a reminder with a one-click switch to a limit order, avoiding accidental market fills in pre-/post-market sessions.
- Reconnecting and disconnected states now show a status indicator with manual retry, so a stalled quote feed is no longer left to guesswork.
