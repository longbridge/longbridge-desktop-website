# v0.20.0 

_Release Date: 2026-09-09_

### New features

- **LongbridgeAI**: It thinks, it acts, and it's ready to analyze whenever you ask — LongbridgeAI is now live.
  - Instant access: available as a sidebar or fullscreen, one click away from any screen.
  - AI stock analysis: a single question covers fundamentals, technicals and news, summarized into a conclusion.
  - AI stock screening: describe a screening idea in one sentence and LongbridgeAI turns it into filter conditions.
  - AI trend analysis: select a range on the chart and LongbridgeAI explains what drove the move.
- **Trade**: New take profit / stop loss attached-order templates — apply one to the order form in a single click, with no need to type trigger prices every time.
- **Options**: Option analysis gains a "Strike price" statistics module with volume and open interest analysis, so you can see where contracts cluster.
- **Trade**: New HK price protection alerts. A dialog warns you up front when an order price sits too far from the order book, and the order list now labels orders that are being held — so they're no longer mistaken for failed submissions.
- **Grid trading**: New tabs offer a "Grid trading" template — one click opens a professional swing-trading workspace.
- **Order**: Trade push notifications now reach the system notification center, so fills land the moment they happen, even with the desktop app in the background.

### Improvements

- The stock detail panel is now responsive — fields reflow into fewer columns in narrow windows, so nothing gets cut off on a small screen.
- Chart quick trading feels cleaner: quantity and focus no longer linger after an order is placed, and take profit / stop loss can be filled with your full position, tracked dynamically, in one click.
- Refreshed the icons for the data-column drawing tools in the chart, so they're easy to tell apart in the dropdown.

> LongbridgeAI responses are generated by AI and are for reference only. They do not constitute investment advice.
