# v0.20.0 

_Release Date: 2026-09-09_

### New Features
- Added support for completing OpenAPI scope authorization within the app for improved convenience.

### Improvements
- Optimized the context pass-through for the 'Ask AI' feature to ensure consistency along the ACP path.
- Adjusted screener logic to honor returns and tool's sort order specified in screener parameters.
