# v1.0.0-preview.3  <Badge type="warning" text="preview" />

_Release Date: 2026-10-09_

### New Features

- **LongbridgeAI**: Redesigned the reasoning process, making the AI's progress easy to follow and keeping answers focused.
- **Stock Details**: Added a hot topic card to the pinned board, showing trending discussions about the stock and linking straight to the topic page.
- **Trade**: Added Touch ID unlock for trading on macOS — verify your trade password with just a fingerprint.
- **Account**: Added account switching, so you can switch to any previously signed-in account from the avatar menu without logging out and back in.
- **Chart**: Added "Signals & Catalysts" to the K-line chart, marking trading signals and catalyst events on the chart; open one to see the details or ask AI to analyze it, helping you quickly understand what drives a move.
- **Custom Layout**: Added undo, so accidentally removed widgets or a messed-up layout can be restored at any time; tabs can be exported to a file and imported on another device, making layouts easy to share and migrate.
- **Announcements**: New announcements are also sent to the system notification center while the app is in the background, so important notices are not missed.

### Improvements

- Added display settings to the heatmap for customizing titles, values, colors and grouping; also improved the layout so small blocks are no longer squeezed into thin strips.
- The Today's Orders popover in chart trading now shows the strategy name and leg details of multi-leg option orders.
- Fixed an issue where a full leap-year range was rejected as longer than one year when exporting historical orders.
- Dragging a widget into an empty custom layout now shows the drop area, and the widget toolbox hides automatically while you adjust panels so it no longer covers the canvas.

### 新增功能

- **LongbridgeAI**：思考过程全新改版，推理进展一目了然，回答更聚焦。
- **个股详情**：置顶栏新增热门话题卡片，展示与该股相关的热门讨论，点击直达话题页。
- **交易**：macOS 支持用触控 ID 解锁交易，验证交易密码时按一下指纹即可。
- **账号**：新增切换账号，在头像菜单中即可切换到登录过的账号，无需退出后重新登录。
- **图表**：K 线新增「交易机会与驱动因素」，在图上标出交易信号与催化事件，点开即可查看详情或交给 AI 解读，帮助快速了解走势背后的原因。
- **自定义布局**：支持撤销，误删组件或调乱布局可随时恢复；标签页可导出为文件、在其他设备导入，方便分享和迁移布局。
- **公告**：应用在后台时，新公告同时推送到系统通知中心，不会错过重要通知。

### 优化

- 热力图新增显示设置，可自定义标题、数值、配色和分组方式；同时优化布局，小板块不再被挤成细条。
- 图表交易的今日订单弹窗正确展示多腿期权订单的策略名称和各腿信息。
- 修复了导出历史订单时，闰年的整年区间被判定为超过一年的问题。
- 向空白自定义布局拖入组件时显示放置区域；在布局中调整面板时自动隐藏组件工具箱，不再遮挡画布。

### 新增功能

- **LongbridgeAI**：思考過程全新改版，推理進展一目了然，回答更聚焦。
- **個股詳情**：置頂欄新增熱門話題卡片，展示與該股相關的熱門討論，點擊直達話題頁。
- **交易**：macOS 支援用觸控 ID 解鎖交易，驗證交易密碼時按一下指紋即可。
- **賬號**：新增切換賬號，在頭像選單中即可切換到登入過的賬號，無需登出後重新登入。
- **圖表**：K 線新增「交易機會與驅動因素」，在圖上標出交易訊號與催化事件，點開即可查看詳情或交給 AI 解讀，幫助快速了解走勢背後的原因。
- **自定義佈局**：支援撤銷，誤刪組件或弄亂佈局可隨時還原；標籤頁可匯出為檔案、在其他裝置匯入，方便分享和遷移佈局。
- **公告**：應用程式在背景執行時，新公告同時推送到系統通知中心，不會錯過重要通知。

### 優化

- 熱力圖新增顯示設定，可自訂標題、數值、配色和分組方式；同時優化佈局，小板塊不再被擠成細條。
- 圖表交易的今日訂單彈窗正確顯示多腿期權訂單的策略名稱和各腿資訊。
- 修復了匯出歷史訂單時，閏年的整年區間被判定為超過一年的問題。
- 向空白自定義佈局拖入組件時顯示放置區域；在佈局中調整面板時自動隱藏組件工具箱，不再遮擋畫布。
