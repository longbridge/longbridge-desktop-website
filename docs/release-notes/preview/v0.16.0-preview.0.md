# v0.16.0-preview.0  <Badge type="warning" text="preview" />

_Release Date: 2026-04-30_

### New Features

- **Chart**: Added Y-axis zoom, allowing users to scale price ranges independently for reviewing volatile periods.
- **Chart**: Added a right-click context menu on the main quote chart, surfacing K-line type / Adjust type / Time-share mode / Open Trade / Chart settings without trips to global settings.
- **Quotes**: Added activities that surface recent corporate actions and key news at a glance in both quote detail and watchlist views.
- **Option Chain**: Added a financial report panel inside the option chain so traders can check fundamentals without switching panels.
- **Portfolio**: Redesigned "Margin Status" view with more margin information and credit-line adjustment.
- **Announcements**: Added system-wide announcements.
- **Login**: Added password reset.

### Improvements

- Order push notifications now show the account name and mute the success sound for demo accounts, so users won't mistake a paper trade for a real one.
- Fixed state interference when rapidly modifying multiple orders via quick-replace.
- Improved the trade password flow — once verified, users no longer need to repeat actions like withdrawing orders.
- Fixed assets showing no data after switching from an account that requires a trade password to one that doesn't
