# v1.0.0-preview.1  <Badge type="warning" text="preview" />

_Release Date: 2026-09-08_

### New Features
- Added a HoverCard on the attached-order switch to display the disabled reason, helping users understand why the function is unavailable.

### Improvements
- Improved CYQ entry stability when switching indicators panels to prevent display jolts.
- Made the collapse state of script list section in quant persistent, allowing user-defined interface setups.
