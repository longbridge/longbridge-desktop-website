# v0.16.0-preview.1  <Badge type="warning" text="preview" />

_Release Date: 2026-05-14_

### New Features

- **Chart**: Added "Interval Statistics".
- **Announcements**: Added announcements so you can stay on top of important notifications.
- **Assets**: Revamped the "Financing Status" panel with a clearer, more professional asset breakdown and support for credit limit adjustments.

### Improvements

- Fix incorrect estimated post-trade holding cost display when closing positions.
- Optimized option chain scroll synchronization.
- Optimized the login flow to avoid unexpected session expiration behavior.
