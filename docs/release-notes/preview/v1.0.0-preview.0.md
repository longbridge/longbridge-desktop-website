# v1.0.0-preview.0  <Badge type="warning" text="preview" />

_Release Date: 2026-09-07_

### New Features

- **AI Assistant**: Released the AI assistant. Ask in plain language for quotes, stock analysis, account assets and P&L, use @ to pull stocks and signals into the context, and get answers with quote cards, intraday and candlestick charts embedded inline; it can also write quant strategies and interpret backtest reports. Available as a sidebar or in fullscreen, where chat history is searchable.
- **Trade**: Added take-profit/stop-loss order templates that can be applied to the order form in one click and managed centrally in settings, so trigger prices no longer have to be typed in every time.
- **Options**: Added a "Strike Distribution" section to option analysis, using a call/put diverging bar chart and an in-the-money/out-of-the-money summary table to make the distribution easy to read.
- **Trade**: Added HK price protection alerts — when an order price sits too far from the order book, the app explains up front that the order will be held, so it is no longer mistaken for a failed submission.
- **Grid Trading**: Added a "Grid Trading" tab template that lays out the daily candlestick chart, grid orders and today's/historical orders on one screen, ready to run a grid strategy out of the box.
- **Order**: Trade push notifications now reach the system notification center, so fills show up right away even when the app is in the background.

### Improvements

- Made the stock detail panel layout responsive, so fields reflow into fewer columns in narrow windows.
- Improved chart quick trading — quantity and focus no longer linger after an order is placed, take-profit/stop-loss can be filled with the full position quantity in one click, and the orders list shows that quantity as well.
- Brought the entire options tab under panel lazy-loading, so it no longer issues network requests or quote subscriptions while off screen, noticeably reducing background overhead.
- Gave the chart drawing tools dedicated icons and renamed the Fibonacci tools, making them easier to tell apart.
- The P&L page's display currency now follows the account preference, keeping it consistent with account settings.
