# v0.18.0-preview.0  <Badge type="warning" text="preview" />

_Release Date: 2026-07-13_

### New Features

- **Trade**: Added customizable trading shortcuts — quick buy/sell at market, bid, or ask price, one-key market close and fast order cancellation, with per-market preset order quantities, so trades can be completed without leaving the keyboard.
- **Trade**: Added combination options support covering order placement, P&L analysis, order push updates, and holdings display, so option strategies can be placed and tracked directly on desktop.
- **Trade**: Added the MOC (Market-on-Close) order type for US stocks, making it easy to fill at the closing price.
- **Options**: Added an Options panel combining option chain, unusual activity, and analysis sub-tabs, bringing options data together in one place.
- **Assets**: Added "group derivatives by underlying" display in the holdings list — a stock and its options, combination options, and warrants/CBBCs are grouped with aggregated P&L for a clearer view of positions.
- **Stock Details**: Added an ETF overview panel showing the tracked index, expense ratios, Morningstar ratings, historical performance, composition, and dividends, helping users get up to speed before buying.

### Improvements

- Optimized option chain loading performance — only visible rows fetch quotes, with lazy rendering of updates for smoother scrolling on long lists.
- The watchlist now displays custom stock name remarks.
- Moved the News tab into the quotes panel group for easier browsing of stock news.
- "Buy / Sell" items in the holdings context menu are colored with trend colors, making the direction obvious at a glance.
- Columns such as holding ratio and close price now sort numerically, fixing incorrect sort order.
