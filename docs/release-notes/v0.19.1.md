# v0.19.1 

_Release Date: 2026-08-20_

### Improvements

- Fixed an issue where the editor could quit unexpectedly in certain syntax highlighting cases — editing content with multi-byte characters such as Chinese is now more stable.
- Fixed vertical lists occasionally showing an unnecessary horizontal scrollbar — overlong text now truncates correctly to the actual list width.
