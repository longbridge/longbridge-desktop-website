# v0.16.0 

_Release Date: 2026-05-20_

### New Features

- **Chart**: Added K-line "Interval Statistics", making it easier to monitor and review price action.
- **Chart**: Added a right-click context menu so users can switch K-line type, adjust type, or open the trade window without going to Global Settings.
- **Chart**: Added Y-axis zoom for adjusting the price axis independently and reading local movements more clearly.
- **Trade**: Options trading now supports attached orders (stop-loss / take-profit).
- **Announcements**: Added system announcement notifications so important messages are no longer missed.
- **Stock Reminder**: Added push notification support — alerts arrive in real time once triggered, so users never miss a key price.
- **Quotes**: Added activity tags (earnings, dividends, IPOs, important advisories, etc.) — key events at a glance.
- **Option Chain**: Added financial report data.
- **Option Chain**: Bid/ask prices can be sent directly into the trade form, shortening the options ordering path.
- **Assets**: Brand-new "Financing Status" page with more financing details and credit-limit adjustment.
- **Login**: Added a password reset flow for "Forgot password", completed entirely inside the client.

### Improvements

- Order push notifications now show the account name, and success sound is muted for demo accounts so simulated orders are no longer mistaken for real ones.
- Fixed state interference when quick-editing several orders in rapid succession.
- Improved the trade password flow — actions like withdraw continue automatically after a successful verification, no second click required.
- Fixed incorrect holding cost displayed after estimated fill on position close.
- **Login**: Streamlined the login flow to avoid unexpected session expiration, improved the captcha network-error prompt, and added a retry mechanism.
