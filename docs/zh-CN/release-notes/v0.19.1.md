# v0.19.1 

_发布日期： 2026-08-20_

### 优化

- 修复了编辑器在部分语法高亮场景下可能意外退出的问题，编辑含中文等多字节字符的内容时更稳定。
- 修复了纵向列表偶尔出现多余横向滚动条的问题，超长文本现在会按列表实际宽度正确截断显示。
