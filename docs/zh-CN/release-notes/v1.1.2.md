# v1.1.2 

_发布日期： 2026-11-10_

### 优化

- 修复了 LongbridgeAI 语音输入识别的问题。
- 修复了持仓切换市场分组可能不生效的问题。
- 修复了带止盈止损的订单主单成交后，待触发的止盈止损线从 K 线上消失、无法拖拽改价的问题。
- 提升了 Windows 上的运行稳定性，优化了系统睡眠唤醒后的恢复表现。
- 修复了期权链组件改为不联动或其他联动分组后，期权表格和期权异动没有跟随自己分组的问题。
