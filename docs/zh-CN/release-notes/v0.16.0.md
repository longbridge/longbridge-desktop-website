# v0.16.0 

_发布日期： 2026-05-20_

### 新增

- **图表**：新增 K 线「区间统计」功能，方便看盘和复盘。
- **图表**：新增右键菜单，无需进入全局设置即可快速切换 K 线类型、复权类型，或打开交易窗口。
- **图表**：新增 Y 轴缩放，可独立调整价格轴比例，方便看清局部走势细节。
- **交易**：期权交易支持附加订单（止盈止损）。
- **公告**：新增系统公告通知支持，避免重要信息被错过。
- **股票提醒**：新增推送通知支持，提醒触发后可实时送达，避免错过关键价位。
- **行情**：新增活动标签（业绩、分红、新股、重要咨询等），关键事件一目了然。
- **期权链**：新增财报数据展示。
- **期权链**：买卖盘价格支持直接带入下单表单，期权下单链路更短。
- **资产**：全新的「融资状态」界面，支持更多融资相关信息查看和调额功能。
- **登录**：新增忘记密码的密码重置流程，可直接在客户端内完成。

### 优化

- 订单推送通知新增账户名展示，并对模拟账户静音成交提示音，避免把模拟单误认为实盘。
- 修复了快捷改单多订单快速改单时的状态干扰。
- 优化交易密码流程，撤单等功能校验成功后无需重复操作。
- 修复平仓时，预估成交后持仓成本显示错误的问题。
- **登录**：优化登录流程，避免意外的登录状态过期行为，优化图形验证码网络异常提示，新增重试机制。
