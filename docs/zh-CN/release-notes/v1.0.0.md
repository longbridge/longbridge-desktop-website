# v1.0.0 

_发布日期： 2026-09-07_

### 新增

- **LongbridgeAI**：思考过程全新改版，推理进展一目了然，回答更聚焦。
<video src="https://assets.lbkrs.com/uploads/041485a2-c969-4d21-a589-19efb7f0191f/AI.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>
- **个股详情**：置顶栏新增热门话题卡片，展示与该股相关的热门讨论，点击直达话题页。
- **交易**：macOS 支持用触控 ID 解锁交易，验证交易密码时按一下指纹即可。
- **账号**：新增切换账号，在头像菜单中即可切换到登录过的账号，无需退出后重新登录。
<video src="https://assets.lbkrs.com/uploads/8efdf487-a79f-410f-a2d5-832e54f8f72b/Accounts.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>
- **图表**：K 线新增「交易机会与驱动因素」，在图上标出交易信号与催化事件，点开即可查看详情或交给 AI 解读，帮助快速了解走势背后的原因。
- **自定义布局**：支持撤销，误删组件或调乱布局可随时恢复；标签页可导出为文件、在其他设备导入，方便分享和迁移布局。
<video src="https://assets.lbkrs.com/uploads/bffd7355-e057-482c-b68c-05ee440c344e/Layout.mp4" type="video/mp4" autoplay muted loop>Your browser does not support the video tag.</video>
- **公告**：应用在后台时，新公告同时推送到系统通知中心，不会错过重要通知。

### 优化

- 热力图新增显示设置，可自定义标题、数值、配色和分组方式；同时优化布局，小板块不再被挤成细条。
- 图表交易的今日订单弹窗正确展示多腿期权订单的策略名称和各腿信息。
- 修复了导出历史订单时，闰年的整年区间被判定为超过一年的问题。
- 向空白自定义布局拖入组件时显示放置区域；在布局中调整面板时自动隐藏组件工具箱，不再遮挡画布。
