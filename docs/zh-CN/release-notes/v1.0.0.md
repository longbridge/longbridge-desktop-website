# v1.0.0 

_发布日期： 2026-09-07_

### 新增

- **LongbridgeAI**：能思考，会行动，随时为您分析的 AI 助手正式上线。
  - 即时唤起：侧边栏与全屏两种形态，任意界面一键提问。
  - AI 个股分析：一次提问覆盖基本面、技术面、消息面，自动汇总成结论。
  - AI 智能选股：一句话说清选股思路，AI 自动转成筛选条件。
  - AI 趋势解读：框选一段区间，AI 解读走势成因。
- **交易**：新增止盈止损附加单填写模板，下单表单一键快捷套用，无需每次手填。
- **期权**：期权分析新增「行权价」统计模块，支持成交量和持仓量分析，筹码堆在哪里一目了然。
- **交易**：新增港股保价提醒。下单时价格偏离盘口过远会弹窗提醒，订单列表中订单被保价时也会显示提示文案，不会再误以为下单失败。
- **网格交易**：新开标签页新增「网格交易」模板，可快速点击一键使用，专业的波段交易工具。
- **订单**：成交推送接入系统通知中心，桌面端在后台时也能第一时间收到成交提醒。

### 优化

- 个股详情面板升级为响应式布局，窄窗口下字段自动换列，小屏也能读全。
- 图表快捷交易更顺手：下单后数量与焦点不再残留，止盈止损可一键填入动态全仓。
- 图表画线中，数据列画线工具图标优化，下拉菜单里一眼分得清。
