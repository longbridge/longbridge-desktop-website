# v0.20.1 

_发布日期： 2026-09-24_

### 优化

- 修复了下单价格跟随「中间价 / 买一 / 卖一」时，只在有新成交时才刷新的问题；成交稀少的期权限价单不再因价格滞后而追不上盘口。
- 修复了改单未触发的全仓止盈止损单时，确认框中预估金额始终显示为 0 的问题。
- 优化图表指标的计算性能，行情推送引起的图表重建耗时降低约 60%，多图表布局下盘中操作更流畅。
- 修复了打开多个副图指标时，只有最上方的分隔线可以拖动的问题。
