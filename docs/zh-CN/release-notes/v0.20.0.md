# v0.20.0 

_发布日期： 2026-09-09_

### 新增
- 支持用户在应用内完成 OpenAPI 范围授权，提升便捷性。

### 优化
- 优化了「问 AI」功能的上下文传递，确保在 ACP 路径中保持一致。
- 调整了筛选器逻辑，支持从筛选参数中继承回报率和工具排序规则。
