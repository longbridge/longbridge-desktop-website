# v0.19.0-preview.1  <Badge type="warning" text="preview" />

_发布日期： 2026-08-19_

### 优化

- **量化**：指标设置面板新增「缩写」输入项，支持唯一性校验、保存后锁定，不再只能以指标名称作为标识提交。
- 修复止盈止损盈亏率点击加减号时小数位被抹掉的问题（如 10.23 点加号后变成 11 而非 11.23）。
- 网格交易推送通知底部现会显示归属账户，多账户下可分清推送来源；「暂停」通知改为成功样式，不再显示为警告。
- 修复网格交易下单窗口在 Windows 上缺少最小化/最大化/关闭按钮的问题。
- 修复股票筛选器首页描述过长时不换行溢出、网格交易提交成功提示不显示文案的问题。
