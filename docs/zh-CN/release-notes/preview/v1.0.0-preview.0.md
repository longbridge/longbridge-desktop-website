# v1.0.0-preview.0  <Badge type="warning" text="preview" />

_发布日期： 2026-09-07_

### 新增

- **AI 助手**：发布 AI 助手。可以用自然语言查行情、分析个股、查看账户资产与盈亏，@ 引用个股与信号补充上下文，回答中直接嵌入行情卡片、分时与 K 线图表；还能生成量化策略、解读回测报告。提供侧边栏与全屏两种模式，全屏下可搜索历史对话。
- **交易**：新增止盈止损订单模板，下单表单可一键套用、设置页统一管理，不必每次手填触发价。
- **期权**：期权分析新增「行权价分布」板块，用看涨/看跌双向柱状图与实值/虚值汇总表看清筹码分布。
- **交易**：新增港股保价提醒，下单价格偏离盘口过远时提前说明订单会被暂存，不会再误以为下单失败。
- **网格交易**：新增「网格交易」标签页模板，日 K 图表与网格订单、今日/历史订单一屏排布，开箱即可开始网格策略。
- **订单**：成交推送接入系统通知中心，App 在后台时也能第一时间收到成交提醒。

### 优化

- 个股详情面板改为响应式布局，窄窗口下字段自动换列。
- 优化图表快捷交易：下单后数量与焦点不再残留，止盈止损可一键填入全部持仓数量，委托列表同步展示该数量。
- 期权标签页全面接入面板懒加载，不在屏幕上时不再发起网络请求与行情订阅，后台开销明显下降。
- 图表绘图工具改用专属图标并重命名斐波那契系列，工具更容易分辨。
- 盈亏页的显示币种改由账户偏好决定，与账户设置保持一致。
