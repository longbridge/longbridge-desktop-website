# v0.18.2-preview.0  <Badge type="warning" text="preview" />

_发布日期： 2026-07-23_

### 新增

- **财务**：个股财务新增「业绩」「收入构成」「股东回报」三大板块，财报关键数据图形化呈现，帮助快速把握公司基本面。
- **交易**：多腿期权组合（MLEG）支持市价单下单，组合策略不再局限于限价方式。
- **交易**：下单预估费用支持卡券抵扣前后对比展示，预览金额与实际冻结口径一致、所见即所得。

### 优化

- 平仓操作统一为强制二次确认后直接提交，不再弹出下单面板，流程更快且避免误操作。
- 「当日订单」快捷改单升级：数量与委托价可直接输入，改单更高效。
- 修复条件单选择市价类型时，预估金额和最大可买数量未按触发价计算的问题。
- 误按提示浮层现在会列出包含所按修饰键的全部快捷键，且主快捷键优先展示，便于发现可用操作。
- 修复期权链在切换标的或到期日后，可见合约行情不加载的问题。
- 期权策略简介的盈亏示意图全新设计，用涨跌色区分盈亏区间并标注盈亏平衡点与最大盈亏，策略特征一目了然。
- 修复深度摆盘在切走标签页再切回后数据不再更新的问题。
- 持仓右键菜单的「买入」「卖出」按涨跌色显示，操作方向更醒目。
